# 提问模板（2026-10-02 第四篇文章实测可用）

使用时把 `[用户原始思路]` 替换为用户给的原文（逐字引用，不得改写）。

## 模板一：框架征集（阶段一，发给 ChatGPT 和 Claude，同一个问题）

```
我是一位教授、经济学博士、资深投资人，运营一个关注投资、AI 趋势与个人成长的中文公众号。下面是我的原始思路，请忠实理解其核心思想：

"[用户原始思路]"

请基于以上思路，帮我构思一篇"思想深入、引人深思"的公众号文章框架。要求：
1. 完整保留原文核心思想，不得扭曲、不得弱化其反常识的锋芒
2. 给出：切入角度、核心论点与分论点、4-6 节大纲（每节标题、核心观点、论据方向，可引入经济学视角如复利、机会成本、人力资本、风险）
3. 每节给 1 条金句方向
4. 给出 3 个标题备选
5. 风格犀利、有洞察、有反常识的快感，但论证扎实；用简体中文
6. 这次只要框架，不要写成稿

写作背景：作者人设是教授、经济学博士、资深投资人；读者关心投资、AI 趋势与个人成长。
```
